# 学习资料

你目前从零基础开始，建议按以下顺序阅读：

1. 先读对应的 [NASA 原报告](../reports/README.md)，认识压气机和透平各自解决什么问题。
2. 阅读 [离心压气机零基础教程](tutorials/离心压气机程序_零基础全符号与概念详解.md)。
3. 阅读 [向心透平零基础教程](tutorials/向心透平程序_零基础全符号与概念详解.md)。
4. 配合 [早期整体使用指南](tutorials/NASA叶轮机械FORTRAN程序完全解析与使用指南.md)，再看 [修复版源码及运行说明](../restored/README.md)。
5. 用 [来源映射](../restored/SOURCE_MAP.md)、[勘误](../restored/ERRATA.md) 和 [验证结果](../restored/SCAN_RESULTS.md) 核对每个结论。

三份教程作为原始资料原样保存，尚未逐项完成教学内容审查；其中绝对化表述、旧文件路径和“完全一致”等说法不能视为已经验证的结论。例如静止部件总温不变需要绝热、稳态且无轴功等前提；已有可信设计系数时，不必把 MODE=2 当作每次运行的第一步。

程序当前状态见 [STATUS.md](STATUS.md)。目录搬迁及原文件保护见 [ORGANIZATION.md](ORGANIZATION.md)。
