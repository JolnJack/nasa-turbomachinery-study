# 原始本地文件

此处保存整理前根目录的本地转录源码、输入、输出、旧可执行文件及 Makefile，内容没有修改。它们不是已经取得并认证的 NASA 官方分发文件。

原始14文件中的 PDF 在 `reports/`，三份原教程在 [tutorials/](tutorials/)；完整位置映射及原始哈希见 [manifest.json](manifest.json)。独立基线副本继续保存在 `audit/2026-10-22/baseline/`。`docs/tutorials/` 是经过修订的学习版本；此处原教程包含已发现的错误和旧路径，只用于追溯，不作为当前运行说明。

日常运行请使用 [现代修复版](../restored/README.md)。此处旧 Makefile 会吞掉部分运行错误，旧二进制也不保证适配其他电脑，保留它们是为了核对早期状态。
