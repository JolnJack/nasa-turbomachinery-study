## 工程修正

| 问题 | 根因与处理 | 证据 |
| --- | --- | --- |
| 压气机 MWRMS / DIFLEM 越界 | 原搜索无端区间出口；使用最近端区间作线性延伸，表内算法不变 | 60% 样例 RMRMS=.454712331，表下限 .5；修复后数组检查通过，兼容版参考470/470 |
| AR=3/4/5 跳变 | 原严格不等式排除节点，落入首区间；改为相邻区间含节点 | 五个节点与两侧连续性检查；原3/4/5失败记录保留 |
| EOF 与无效输入混淆 | 新记录读取器验证组名、结束符、截断及尾部内容，再由 Fortran 自身解析 NAMELIST | 空输入、错误数值、错误组名、截断、垃圾输入；正常0，错误非0 |
| 压气机局部输入继承错误 | 上一组角度被弧度化，省略字段时重复换算；保存原输入角度供下一 namelist 使用 | 完整第二组输入与只覆盖 NONDES 的第二组输入结果一致 |
| 透平标题丢字 | 用数值存储读 A6，字长不兼容；改为 CHARACTER*6 | 六模式标题核验 |
| 扫描端点漏段 | 累加误差略大于 VMAX；仅在当前算术8个ulp窗口内包含端点，并限制到上限 | 原 .30/.05/.80 输入从10行恢复20行；原生与兼容均验证 |
| 超临界静叶作为首点的入口速度为0 | 原分支跳过入口连续性；改为复算入口流量和速度 | 合成 V1=1.05、A5=.02：V0VC0从0恢复约.061208 |
| 预旋输入回显 `****` | F4.2 宽度不足 | 扩宽输入回显字段，正预旋功能测试通过 |
| 非法数值域触发异常 | 在执行方程前检查有限值、长度、正物性/几何和已刊表的面积比范围 | 无效 GAM、NVOVCR、VLDRR、AR、MODE、DELV、A1 等明确返回错误 |
| 设计流量不可达到 | 设计流量超过静叶理论最大通流量，牛顿初值进入无物理解 | 按 SUBR(1,G) 容量判据返回明确无解状态 |
| 逆设计失败仍沿用状态 | 原90分支直接读下一组，弧度角和未收敛系数被下一组部分输入继承 | 新合成目标触发后曾输出异常并退出-4；修复版明确返回2、性能块0；历史清单不改，由包装器拒绝无解及错误追踪输出 |
| 构建隐藏失败 | 根目录 Makefile 吞掉 stderr/状态；复原版不使用这一方式 | build、run 与严格原表对照的真实退出状态保留 |

端区间延伸是为使合法低速样例可计算所作的明确工程选择，采用与已刊 LININT 相同的端区间思想；不能据此声称公开范围之外的所有外推有实验验证。数值域检查限制了扩压器 AR 在已刊表1.2–5之间。

## 数值兼容变换

源代码仍可直接编译为原生单精度。生成器另对实数常数、输入、算术表达式和初等函数结果施加统一27位向零截断，以128位承载，避免依赖宿主32位中间舍入。整数和输入输出语义另行保留。逐条变换保存在 `compat27/generation.json`。

没有增加针对某个流量/转速点的修正，没有改动损失关联式、经验表、原迭代容差或原始参考答案。报告的 G13 显示适配仅依据可见打印位数，并非历史计算机格式的全面认证。

## 独立历史后端

`tools/prepare_historical.py` 固定公开 s709/IBSYS 档案哈希并在审计目录构建。`run_historical_turbine.py` 读取根目录原透平清单，仅生成作业控制、输入传输和输出格式适配；原物理计算语句保留。FASC 例程来自存档 IBM 库，ASIN/ACOS 只是原 ARSIN/ARCOS 入口的符号别名。逐字段输入保留后续记录部分赋值语义，因此设计系数可在内部完整继承。

机器字输出和解码用于独立记录数值，不向待验程序提供参考答案。`tests/check_historical.py` 保留原表 II、舍入系数、完整内部继承三种对照；检查公式优先验收和原始打印表验收的不同状态。详见 `TURBINE_FINDINGS.md`。

## 扩展扫描后的新增处理

- 压气机在性能输出前检查效率、压比、正流量及各损失项非负。负扩压器损失的原计算保留在失败证据中；没有把负值裁剪为零，且这些工况尚无可靠性能预测。
- 透平在额外性能参数计算前拒绝非正功/不合法效率，防止对负焓降作分数次幂。
- 透平现代版用独立整数计数器限制总迭代为200000次，覆盖重复堵塞细分。超过预算返回2；不宣称数学无解，也不改变已刊局部迭代容差。
- `turbine_design_solver.py` 是单独标明的工程改进。先对原Fortran正算方程作有界阻尼搜索；近堵塞时依据欧拉功、质量连续性与原损失关系消元，保留普通旧求根对照，独立检验质量、两种能量及损失残差。无目标系数作为初值，无物理常数拟合。16个代数分支解不宣称与旧 CONTIN 求根过程逐位等同。
- `modern64` 只更换计算精度，原生32位、27位兼容与历史后端保留。详见 `SCAN_RESULTS.md`。
