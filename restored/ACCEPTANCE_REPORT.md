# 最终验收报告

编制日期：2026-10-25。对象：TN D-7487 离心压气机程序、TN D-8063 向心透平程序的现代修复版、27 位兼容版、64 位工程版和 IBM 7094 历史后端，以及配套教程与审计证据。

## 1. 验收结论

**最终验收：不通过。** 按 [WORK_PLAN.md](WORK_PLAN.md) 的规则“未通过项目不作通过声明”，下列任一项未闭合，整体即不能判为通过：

1. 现代透平严格原表比较失败，`make test` 按预期返回 2（见第 4 节 A7）。
2. 透平 SI 输出 `N`、`TOR`、`NS` 等字段存在已证实的单位尺度混用，尚未修正（A11）。
3. 连续输入域、全部实验图、第二台实验透平、编译平台以及与 NASA 分发源文件的逐字身份均未验证（第 5 节）。
4. WORK_PLAN 第 7 项“解释数值差异及报告内部矛盾，扩展功能、单位制、边界与失败测试”大部分已做，但单位制修正和全部失败组合未完成，仍未勾选。

**可接受的有限用途：** 学习两份报告的方法；复核公开的 NASA 参考算例；用 64 位工程版在已扫描网格附近做离线科研探索，同时每次检查收敛、守恒和拒绝信息。**不可接受的用途：** 把输出直接作为 He–Xe 机组的设计或认证依据；直接使用透平 SI 的 `TOR`、`NS`、`TOR/P` 等字段；把功能回归、扫描或逆设计计数称为实验验证。

## 2. 验收依据与口径

- 规则来源：[WORK_PLAN.md](WORK_PLAN.md) 的验收规则。印刷参考值首先逐位比较，差异原样保留；诊断输入、工程扩展与 NASA 样例分开标记；未说明依据不改物理常数、容差或参考数据。
- 用户已作的选择：报告公式与印刷表矛盾时，以公式和程序清单为准，保留原表，另列勘误证据。该口径只用于判断 E1，不把严格比较的失败改写为通过。
- 守恒检查阈值（质量 ≤3e-5，能量 ≤5e-6）是数学一致性判据，不是对原表比较的放宽，也不是实验精度。

## 5. 未完成与已知缺陷

**未验证范围**

- 连续输入域内无缺陷；全部几何、超音速及多解分支；静叶容量的精确边界。
- 报告全部实验图的逐点数字化比对；第二台实验透平的几何与试验条件核对。
- 全部非法输入与不收敛输入的组合。
- 历史编译器与数学库的身份；任意编译平台下结果相同；与未取得的 NASA 分发源文件逐字相同。
- 用户 He–Xe 机组的独立物理验证。

**已知、尚未修正的问题**（为保持原表对照而保留，修正须作为另一版本单独验证）

- 透平 SI 派生字段的单位混用（A11）。
- 压气机扩压器积分只推进 9 次。
- 压气机每点对 B1MFB 做 .01745 与 57.29577 往返换算，乘积 .9998111865，会累积角度漂移。
- 小面积比工况出现负扩压器损失和非物理性能时，现代版已改为拒绝，但这些输入仍没有可靠的性能结果。
- 透平 32/27 位低功工况的舍入放大（守恒超界）未消除，只在 64 位版中满足判据。
- 早期审计的完整轨迹已删除，现存摘要中的旧路径不可访问。

## 6. 关闭最终验收所需的工作

按影响从大到小排列：

1. 让现代透平后端通过严格表比较：移植历史后端的运算和数学库行为，并以内部系数继承作为标准路径。或者，由用户书面确定以历史后端作为原表验收后端，同时把现代后端的严格比较改为单列的已知差异。后一种选择属于验收口径变更，需要用户决定。
2. 建立单位一致的透平 SI 输出候选版本，覆盖 `N`、`TOR`、`EQ-TOR`、`TOR/P`、`NS`、`WN/DEL`，并用 SI/美制等效算例验证；原清单版本保留供原表对照。
3. 扩展失败组合测试，补齐压气机 379 组无输出和负损失工况的成因分类。
4. 对报告实验图逐点数字化比对，并核对第二台透平的条件。
5. 在第二种编译器或平台上重跑全套检查。
6. 若用于 He–Xe 机组，用该工质的物性和实测数据另行验证。

## 7. 重跑命令

在仓库根目录执行，需要 Python 3 和 GNU Fortran：

```sh
make check                      # 原件、基线、链接与完整性
make modern                     # 64 位工程版
make run                        # 27 位兼容版运行原样例
make test-functional            # 61 项功能回归
make test                       # 全套；现代透平严格比较失败，预期退出 2
make -C restored test-historical  # 历史后端（会联网下载并按固定哈希校验）
make -C restored scan           # 网格扫描；返回 0 仅表示执行与分类完成
make -C restored test-design-scan
```
