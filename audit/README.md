## 历史证据的可用范围

历史运行曾保存完整轨迹，其中大量明细在精简时移入外部归档。用户随后删除了外部归档文件夹，本仓库不再具备那部分明细的恢复副本。现存摘要中的历史绝对路径和已删除文件引用，仅记录当时位置，不代表对应文件现在仍可访问。

原报告、原件基线、现代修复源码、固定参考数据、测试夹具和现存摘要仍在。按脚本重跑可生成新的结果，但不能把新运行冒充已删除的原始轨迹。

现代构建和缓存不上传 Git；历史运行环境需要通过 `make historical` 按固定哈希重新获取并构建，会联网并增加磁盘占用。普通 `make modern`、`make run` 和功能回归不需要该历史环境。

审计目录按日期保留，旧结论可能被后续结果修订；当前总览以 [SCAN_RESULTS.md](../restored/SCAN_RESULTS.md) 为准。
